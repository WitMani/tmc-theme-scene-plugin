# 场景生活逻辑

用于Stage 1草图规划、英文prompt编写和成品目视验收。以主题世界中的日常使用与通行为依据，保持休闲游戏的简化表现；不要求工程级仿真，不声称完成导航、碰撞或通航净空验证。

优先遵从 [主体摆放空间](placement-space.md)：先保留主体地块、辨识间距和调整余量，再设计满足连接需求的设施。生活逻辑合理但挤占主体空间的方案仍须调整；优先精简冗余设施和装饰，保留必要通行能力。

## 先用途、后设施

先确定地形和主要活动地点（如住宅、广场、车站、作业区），再说明人和载具如何到达、哪些地方需要跨越或换乘，最后安排道路、桥梁、入口与码头。设施数量由连接需求决定，不为了装饰或填空重复增加；无水域或跨越需求的主题不强行添加桥。

## 桥梁位置与朝向

- 每座桥在草图配套说明中记明连接的两处区域、跨越对象、通行用途及选址/朝向理由；沿用已有区域或连接ID，不在图片上加文字。
- 桥梁沿实际跨越方向连接两岸可达地面，结合局部河道走向、合理跨度和两岸道路决定角度。通常以直接、较短的跨越为起点，也允许有路网依据的斜交桥；不强制每座桥与河道严格垂直。
- 河道转弯、支流和道路端点变化时，桥向应随之调整，避免把同一方向的桥沿不同河段机械复制。平行河段或规则街区允许同向桥；不要设角度配额，也不要只为变化随机旋转桥。
- 桥头两端都需落在有宽度的可达地面并接上通路，不能顶住墙、岩壁或建筑背面，不能落在水里或孤立小块上。桥面与接岸处有高差时，应有可见的坡道、台阶或主题合理的过渡；车辆通路不以仅供步行的台阶连接。
- 作为过河通道的桥不能无理由顺河铺设。沿岸栈道、码头可顺岸延伸，但应按实际用途识别，不误判成跨河桥。桥梁与船只共用河段时，要保留视觉上合理的通行空间，避免桥墩、桥面与船体明显相撞或堵死唯一路径。

## 港口与道路

- 港口按主题中的停靠、上下客或装卸需求选址。形成“可通行水域 → 泊位/码头 → 岸上作业或步行空间 → 道路 → 目的地”的可理解关系；不必添加主题未要求的全部港务设施。
- 泊位贴合局部岸线和船型，留出可见的进出水路与停靠空间；码头不能横堵航道，船不能被封在与外部水域不通的小池中。岸上接路处与活动空间不能被建筑或装饰堵死。
- 道路按实际目的地组织主通路、支路及必要的尽端路，宽度与转弯空间适合所服务的人或车。交叉口和桥头连接清楚，不用无意义回环、重复岔路或密集棋盘格填空；规则街区在主题与功能支持时可以保留。

## 控制设施重复

- 同时检查单张场景内的重复和A/B/C之间的差异。避免沿岸等距复制整组港口、沿河等距复制桥、在各地块反复套用同一段路网或“码头＋桥＋十字路口”组合。
- 依据功能与地形调整设施位置、朝向、间距和组合，必要时采用主港与少量停靠点、主通路与支路等层次；这些是可选组织方式，不是每个主题必须配齐的模板。不要只靠换色、镜像或轻微旋转制造变化。
- 每处设施应服务具体地点或流线。没有独立用途的冗余设施优先删减或合并；合理的连续泊位、同向桥和标准路段可以重复，但应避免整片场景机械铺陈。
- 控制重复针对背景设施及空间组织；保留22种原型和实例计划所需的资产复用，不擅自删减已约定的原型或216实例目标。若涉及明确数量或核心目标，先保持契约并调整位置与组合，冲突如实记录。变化不通过新增大量素材种类、碎装饰、扩大环境面积或改变统一标尺实现。

## 其他背景关系

- 道路连接实际目的地；建筑入口朝向道路、院落或可达空地，保留进出空间。合理的尽端路可以终止于住宅或作业区；无用途的断头路、穿墙路和通向悬崖的车道需要修正。
- 码头一侧连接岸上通路，另一侧接触可用水面；车辆、船只与铁路车辆各自有连续且相符的地面、水域或轨道。铁路与站台位置要体现上下客或装卸关系。
- 高地、台地与低地之间的通路应有合理过渡；山体、岩壁、植被和摆放物不能堵住核心入口或桥头。设施尺度服从已有H130标尺，不能靠缩桥、放大人物或增加杂物掩盖连接问题。
- 物件可以在地面内自然转向，所有旋转仍使用同一世界坐标正交投影。相机辅助轴只约束投影，不要求每座桥、每条路、每栋建筑都与辅助轴平行。

## 落实与验收

草图说明用简短关系清单记录“区域A → 道路/桥梁 → 区域B、用途、朝向/高差依据”；无桥主题只记录适用设施。主agent审核港口水陆衔接、道路目的地与每座桥的连接理由，并检查设施数量及分布是否出现无用途的重复，发现明显矛盾先修草图，再生成成品。相关关系写进已有scene-plan的infrastructure.description和适用的goals，不新增强制schema字段。

英文prompt填入本候选的具体设施关系，不能只写“realistic”或“logical”。成品逐项对照草图检查，并在已有检查记录里保存位置、可见证据、问题和结论；同向桥是否合理要结合河道与路网判断。被遮挡或无法辨明的关系记录为未确认，不冒称连通已验证。明显断接、港口堵航道、无依据的重复设施组合或桥向、不合理高差沿用每槽位最多一次成品修正；草图仍沿用最多两轮修订，不新增重试预算。
