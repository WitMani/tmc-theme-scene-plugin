# 背景 B 档：大形体与内部刻画

## 当前生成约束

B 是每个形体的主色加一个主要暗面；形体朝向、遮挡、顶面与侧面负责体积，同一结构面内部不再铺设碎色块。C 不是默认，仅在用户指定时增加一个宽阔亮面。两者都不等于把全图限定成两三种颜色。

| 部位 | B 档处理 | 常见失败 |
|---|---|---|
| 树冠 | 少数大叶团，轮廓宽而圆润，一片主要暗底 | 低对比的多层小叶团、亮斑仍很密 |
| 树干 | 干净主面和一片侧暗面 | 树皮条纹、斑片、沟槽 |
| 草丛芦苇 | 按可排布空间规则减量外移，保留部分整簇概括 | 逐叶逐根叠加明暗 |
| 岩石岸壁 | 主要顶面与侧面，保持真实地形高度 | 装饰性多边形碎面、纵向条带 |
| 桥体栈道 | 桥面、厚度、桥洞与支撑；仅必要结构缝 | 密集木纹、砖格、描缝、压边 |
| 水面地面 | 宽阔色区、少量大流纹、细柔泡沫，保留瀑布 | 草地颗粒、重复水光、细裂纹 |

树木与主要植被允许按 [可排布空间规则](BACKGROUND-PLACEMENT-SPACE.md) 减量外移；保留河流连通、桥数及接岸。重建遮挡区域仍属于推断，不保证像素级一致。逐部件邻近色描边沿用原规则，不以缺失描边作为简化手段。

## 2026-09-15 改进记录

用户先用 A—E 图示指出：最初 A 过平，现有背景接近 E，目标在 B/C。随后实际生成了同一草原布局的 B 与 C，再提供 E/B 页面与离线包。

B 试验提示词将单体收敛为主色与主要暗面，明确去树皮、合并小叶团、省略砖木缝；C 多一个宽亮面。用户继续反馈“感觉还是过于细节了？”，因此当前约束同时检查内部形状数量；不能仅把多层碎面换成低对比颜色。

这次比较是实际生成记录，不是通过认证。已观察到 B 的部分石块仍有额外分面，草丛芦苇仍可进一步概括，描边一致性也待完善。用户要求将该背景生成约束更新到插件并记录比较，不代表这些偏差可以放宽。

A—E 字母为本次刻画尺度，与文档的 V1/V2/V3 历史版本不是同一编号。原示意图仅为规范理解证据，不作为默认场景生成输入；运行时从当前源图或同场景已生成背景取构图与主题。
