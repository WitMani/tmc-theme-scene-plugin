# Stage 2 背景可排布空间

规则：`BG_PLACEMENT_SPACE`；配置 1.6.0；来源：2026-09-16 用户反馈。

> 我觉得非点击类物件需要靠近 画布边缘

以下为已确认方向的执行解释，覆盖旧版树木、植被数量位置保留要求。

- 先识别内部连续可放置地块，道路、岔口和桥头；保持这些区域无非交互立体装饰与侵入投影。内部以宽缓色差和低对比地表纹理维持环境感。
- 石堆、仙人掌、灌木及非交互树木可删减、归并、迁移。少量主题组靠画布外缘，疏密有变化；不必搬走所有原物件，优先删除多余装饰。
- 外缘不是每块地块、道路或河岸边缘；禁止内部装饰包边或外围连续围墙。不给未验证的边缘宽度、数量或面积比例设硬阈值。
- 保留地形高度、河道、水陆分界、桥数位置及接岸；必要崖壁与河床岩石属于结构例外，记录位置和用途，不能为清场改变地形连通。
- B档明暗、内部形状简化和自然水纹泡沫规则继续适用。此规则不用于独立素材。

生成前记录分区意图；生成后将实际背景检查并入本阶段一次集中检查。内部装饰占位、侵入投影、道路桥头受阻、内部包边或外围堆满时标 fail 并阻止正式导出；未查看实际图保持 unreviewed。修改规则本身不代表现有图片通过，也不自动重生成历史运行。
