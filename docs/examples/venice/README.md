## 文档中的目视记录

- **A**：弯曲宽运河与支渠两岸彩色民居均布、桥接岸，贡多拉、巴士、帆船在水中。鹅角色与暖色哑光屋顶清楚；水面白亮纹及花箱偏多，贡多拉深色较重。
- **B**：中央岛状广场、柱廊钟楼聚集，周边小岛以拱桥连接。鹅与船清楚，建筑哑光；广场钟楼偏大、花箱偏多，个别小鹅在水面，水光减弱但仍可见。
- **C**：连续弯曲岸线与支渠串联小广场，右侧钟楼喷泉。鹅角色、各类船与接岸桥清楚；屋顶哑光，花箱偏多，水面白纹仍强。

此案例展示真实效果及候选差异，不表示已经完成美术、导航、碰撞或玩法验收。README 中的调用示例用于说明用法；实际完整运行提示词见来源文档附件，本仓库的模板是可复用基础模板。
